# Adeel Tariq - Tailmate Mobile Portfolio

This is a self-contained static portfolio page tailored for a conversation with Tailmate.

## Files

- `index.html` - the complete shareable portfolio; no build step or external dependency required.
- `README.md` - deployment notes.

## Quick sharing

Open `index.html` locally in a browser, or upload it to any static hosting service.

## GitHub Pages

1. Create a repository and upload `index.html`.
2. In GitHub: Settings -> Pages -> Deploy from a branch.
3. Select the branch containing `index.html` and the root folder.
4. GitHub will provide a public URL.

## Vercel / Netlify

Upload the folder as a static site. There is no build command and no framework.
